# Fonter

Alle fontene ligger lokalt i denne mappa, slik at appen virker uten nett. De er hentet som variable
woff2-filer (latinsk tegnsett) fra Fontsource (cdn.jsdelivr.net/fontsource) og er lisensiert under
SIL Open Font License 1.1 (https://openfontlicense.org). Lisensen tillater fri bruk, også på trykk.

| Fil | Font | Brukt i |
| --- | --- | --- |
| fraunces.woff2, fraunces-italic.woff2 | Fraunces | Retning A |
| schibsted-grotesk.woff2 | Schibsted Grotesk | Retning A |
| bodoni-moda.woff2, bodoni-moda-italic.woff2 | Bodoni Moda | Retning B |
| jost.woff2 | Jost | Retning B |
| bricolage-grotesque.woff2 | Bricolage Grotesque | Retning C |
| figtree.woff2 | Figtree | Retning C |

Når en retning er valgt, slettes fontene til de to andre.
