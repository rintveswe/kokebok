# Fonter

Fontene ligger lokalt i denne mappa, slik at appen virker uten nett. De er hentet som variable
woff2-filer (latinsk tegnsett) fra Fontsource (cdn.jsdelivr.net/fontsource) og er lisensiert under
SIL Open Font License 1.1 (https://openfontlicense.org). Lisensen tillater fri bruk, også på trykk.

| Fil | Font | Brukes til |
| --- | --- | --- |
| bodoni-moda.woff2 | Bodoni Moda | Titler, stegtekst og tall |
| bodoni-moda-italic.woff2 | Bodoni Moda Italic | Ordmerket, romertall og små uthevinger |
| jost.woff2 | Jost | All brødtekst, knapper og etiketter |

Hvordan de brukes står i `design/DESIGNSYSTEM.md`.
